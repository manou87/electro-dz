# Règle marque SwissDZ — prise

## Décision

1. **Logo principal SwissDZ** = la **prise** (icône historique `assets/images/icon.png` / `logo-wirelab-pro-icon.png`). C’est le symbole de marque, pas un logo d’app isolé.
2. **WireLab Pro** utilise cette prise + le texte **WIRELAB PRO by SwissDZ**.
3. **Pins colorés par app** — petite couleur (aplat) sur les **deux pins** pour différencier chaque app. Corps de prise + fil restent blancs monoline.

## WireLab Pro — pins

- **Couleur pins :** rouge SwissDZ `#C41E2E` (même accent que croissant/étoile).
- Fichiers :
  - `logo-wirelab-pro-pins.png` — logo complet (prise + texte)
  - `logo-wirelab-pro-pins-icon.png` — icône seule (prise + pins colorés)
- Versions sans couleur conservées : `logo-wirelab-pro.png` / `logo-wirelab-pro-icon.png`.
