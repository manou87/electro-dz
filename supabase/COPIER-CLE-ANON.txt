ERREUR « Invalid API key » = mauvaise clé dans js/site-config.js

Supabase n’affiche plus toujours le mot « anon ».
Utilisez l’UNE de ces clés (clé PUBLIQUE seulement) :

══════════════════════════════════════════════════════════════
OPTION A — Clé « Publishable » (nouveau nom, 2025+)
══════════════════════════════════════════════════════════════
1. Ouvrez :
   https://supabase.com/dashboard/project/wxiqqcnzcxswdqzubxyt/settings/api-keys

2. Onglet par défaut (API Keys) → section « Publishable key »
   Format : sb_publishable_xxxxxxxx...
   Cliquez sur Copier (icône copie).

   OU menu Connect (en haut) → choisissez « Web » / JavaScript
   → copiez la « Publishable key ».

══════════════════════════════════════════════════════════════
OPTION B — Clé « anon » ancienne (JWT)
══════════════════════════════════════════════════════════════
Même page → onglet en bas :
   « Legacy anon, service_role API keys »
   Copiez « anon » « public » (commence par eyJhbGci...)

NE JAMAIS copier : service_role, sb_secret_, secret

══════════════════════════════════════════════════════════════
INSTALLER LA CLÉ SUR LE SITE
══════════════════════════════════════════════════════════════
cd website
node scripts/set-anon-key.mjs COLLEZ_LA_CLE_ICI
git add js/site-config.js
git commit -m "Clé API Supabase (publishable)"
git push origin main

Attendre 3–5 min → retester login.html → Google
