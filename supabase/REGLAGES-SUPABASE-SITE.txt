--------------------------------------------------------------------------------

     (droits database + auth, ou « All »)
  2. Dans le terminal :
       cd website
       echo "VOTRE_TOKEN" > .supabase-access-token
       node scripts/apply-supabase-site-setup.mjs
  3. (Optionnel Google) :
       export GOOGLE_CLIENT_ID=...
       export GOOGLE_CLIENT_SECRET=...
       node scripts/apply-supabase-site-setup.mjs

ÉTAPE 3 — Google (OBLIGATOIRE si erreur « provider is not enabled »)
--------------------------------------------------------------------------------
  Lien direct :
    https://supabase.com/dashboard/project/wxiqqcnzcxswdqzubxyt/auth/providers

  1. Cliquer sur « Google »
  2. Activer le bouton « Enable Sign in with Google » (vert / ON)
  3. Coller Client ID et Client Secret (voir Google Cloud ci-dessous)
  4. Enregistrer (Save)

  Sans ces 3 points, le site affiche :
    Unsupported provider: provider is not enabled

  Google Cloud Console → APIs & Services → Credentials → Create OAuth client ID
  Type : Application Web
    Authorized redirect URIs (UNE seule ligne Supabase) :
      https://wxiqqcnzcxswdqzubxyt.supabase.co/auth/v1/callback

    Authorized JavaScript origins :
      https://electro-dz.com
      https://www.electro-dz.com
      http://localhost:8765
